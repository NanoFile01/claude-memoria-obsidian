O Claude Code que lembra de tudo

Toda IA esquece você quando o chat fecha. Com o Cérebro, o Claude Code sabe quem você é, em que você trabalha e o que vocês combinaram, em qualquer chat novo. E a memória fica no seu Obsidian.

⚡ Pegar o prompt Ver no GitHub
> em que pé tá meu projeto e o que eu combinei de fazer essa semana?
● Seu app de agendamento está na fase de testes. Ficou combinado terminar a tela de login até sexta e gravar o vídeo no sábado. Quer começar pelo login?
↑ chat novo. Nada foi colado antes.

Como funciona

Sem plugin, sem servidor. Só arquivos de texto no seu computador.

1

Uma pasta pra tudo

Você ganha uma pasta Cerebro com tudo de importante separado por categoria: projetos, código, estudos.

2

Regras fixas

O CLAUDE.md é lido em todo chat: seu idioma, seu nível e a regra de ser honesto e discordar quando você errar.

3

Índice curto

Uma linha por assunto. O Claude lê o índice sempre e só abre a nota completa quando o assunto aparece.

4

Memória no Obsidian

Ele mesmo escreve as notas. Você abre, corrige e vê tudo ligado no Graph View.

O que você precisa ter

Instale antes de colar o prompt.

✓

Claude Code

Precisa de uma conta Claude com acesso ao Claude Code. claude.com/claude-code

✓

Obsidian

Grátis, pra Windows, Mac e Linux. obsidian.md

+

Git (opcional)

Se tiver, o Claude baixa o template sozinho. Se não tiver, ele te pede pra baixar o ZIP.

O prompt

Copie tudo, abra um chat novo no Claude Code e cole. Ele te faz umas perguntas e monta o resto.

📋 Prompt de instalação 
Carregando o prompt...
  1. Clique em Copiar prompt.
  2. Abra o Claude Code numa pasta qualquer e cole num chat novo.
  3. Responda as perguntas dele (nome, idioma, o que você faz, onde criar a pasta).
  4. No final, abra o Obsidian, clique em "Abrir pasta como cofre" e escolha Cerebro/03_Obsidian.
  5. Abra um chat novo e pergunte: "o que você sabe sobre mim?"
⚠️ Cuidados
  • Nunca deixe o Claude salvar senha, token ou chave de API na memória. São arquivos de texto comuns.
  • Se você sincroniza o vault (Drive, OneDrive, Obsidian Sync), a memória vai junto pra nuvem.
  • Ele pode anotar coisa errada. Abra a pasta Claude/ de vez em quando e corrija.
